## 🎓 LESSONS & BEST PRACTICES

### Implemented Best Practices
1. **Multi-stage builds** - Reduced image size by 50%
2. **Health checks** - Service availability verification
3. **Non-root user** - Security first
4. **Alpine base** - Minimal attack surface
5. **Named volumes** - Safe data persistence
6. **Custom network** - Service isolation
7. **Environment config** - Flexible deployments
8. **Automation** - Reduced manual steps

### Avoided Pitfalls
- ~~Large images with dev deps~~ → Multi-stage builds
- ~~Running as root~~ → nodejs user
- ~~No health checks~~ → Configured for all
- ~~Hardcoded values~~ → Externalized to .env
- ~~Lost data~~ → Named volumes
- ~~Service discovery issues~~ → Docker network
- ~~Manual initialization~~ → docker-entrypoint.sh
