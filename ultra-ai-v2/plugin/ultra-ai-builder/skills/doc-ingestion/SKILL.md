## When to use
S2 ingestion of the 113 own .md files listed in DOC_CONVERSION_MAP.csv.

## Procedure
For each row in DOC_CONVERSION_MAP.csv:
1. Read the whole file.
2. Extract atomic facts -> ultra-ai-v2/memory/facts/<domain>.yaml (id, statement, status, source path#heading, source_sha256, confidence, tags). Aspirational business content gets status: IDEAL, tag non-engineering.
3. Repeatable procedures -> extend/create skills; cite source doc in references/.
4. Extract every Mermaid block -> ultra-ai-v2/diagrams/<doc>__<n>.mmd; validate syntax; add machine graph ultra-ai-v2/diagrams/graphs/<id>.json.
5. Log disagreements in ultra-ai-v2/memory/contradictions.md with both citations + resolution (ADR id).
6. Append line to ultra-ai-v2/memory/sources.jsonl (path, sha256, class, targets, stage).
7. Never edit the source file; output only to new paths.

## Verification
- 113/113 in sources.jsonl stage=done|partial|mechanical (pending=0).
- 117/117 diagrams extracted and syntax-valid; 1 known invalid re-expressed in ultra-ai-v2/diagrams/v2/.
- coverage.md regenerated by script.

## Failure modes
