# Open Source Options

This list captures candidate open-source components for ZeroAI.
The final selection should favor local execution, offline support, and maintainability.

## Speech-to-text

- Whisper: strong accuracy, multilingual, widely used
- faster-whisper: faster Whisper inference path
- Vosk: lightweight offline recognition

## Memory

- Mem0: agent memory layer
- Qdrant: local vector search and retrieval
- SQLite: lightweight durable local store

## User interface

- Open WebUI: local LLM interface
- Custom launcher: lightweight ZeroAI control panel

## Orchestration

- n8n: workflow backbone

## Voice assistant base

- OpenVoiceOS: open source assistant foundation

## Model runtime

- Ollama: default local text generation
- AirLLM: resource optimization lane for larger models
